Nom du projet :boutique Mina

Description :
boutique Mina est un mini site e-commerce développé en HTML, CSS et JavaScript.
Il permet à un utilisateur de s’inscrire, se connecter, consulter des produits, les filtrer par catégorie et gérer un panier.
Le projet met en œuvre la manipulation du DOM, la gestion des événements et le stockage local (localStorage).

Objectifs pédagogiques :

* Comprendre la structure d’un site web (HTML5 sémantique)
* Manipuler dynamiquement le DOM avec JavaScript
* Implémenter une authentification simulée côté client
* Utiliser localStorage pour simuler une session utilisateur
* Appliquer des styles modernes avec CSS (responsive design)

Fonctionnalités principales :

* Inscription avec validation (RegEx)
* Connexion avec vérification des identifiants
* Affichage dynamique des produits (JavaScript)
* Filtrage par catégorie sans rechargement de page
* Ajout de produits au panier
* Sauvegarde du panier dans localStorage
* Interface responsive (adaptée mobile et desktop)

Technologies utilisées :

* HTML5 (structure)
* CSS3 (mise en forme, responsive)
* JavaScript (logique, DOM, événements)
* localStorage (stockage côté client)

Organisation du projet :

* index.html : page d’accueil
* content/ : pages secondaires (connexion, inscription, produits, commande)
* style/ : fichiers CSS
* javascript/ : fichiers JavaScript (authentification, produits, panier)
* images/ : ressources graphiques

Instructions d’utilisation :

1. Ouvrir le fichier index.html dans un navigateur
2. Créer un compte via la page "Inscription"
3. Se connecter avec les identifiants créés
4. Accéder à la page "Produits"
5. Filtrer les produits ou en ajouter au panier
6. Consulter le panier dans la page "Commande"

Contraintes respectées :

* Séparation HTML / CSS / JavaScript
* Utilisation de balises HTML5 sémantiques
* Manipulation du DOM
* Filtrage dynamique côté client
* Validation des formulaires avec RegEx
* Utilisation de localStorage
